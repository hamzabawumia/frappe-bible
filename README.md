# Frappe Bible (from zero to hero)

A practical, example-driven guide to learning the Frappe Framework (v15). This repository contains the book content (Markdown) and example exercises.

Goals
- Teach web developers who are new to Frappe how to build Frappe apps and extend the framework.

Quick start :
Navigate the docs/ directory and read the chapters.
you may start from docs/01-foundations/01.Frappe_overview_for_web_developers.md

https://github.com/hamzabawumia/frappe-bible/blob/main/docs/01-foundations/01.Frappe_overview_for_web_developers.md


Structure
- docs/           — chapters written in Markdown (MkDocs site)
- examples/       — example apps and helper scripts
